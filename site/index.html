The problem

Agents write code faster than anyone can read it. After a few sessions, it is your project — but you are no longer sure how it works, which paths a function can take, or what the last change really did.

What Convity does

It reads the code in a folder on your computer and turns each function into something you can explore — without running it.

Understand

Learn how it works

A step-by-step flow graph next to the code, with explanations from plain (L0) to technical (L4). Stop at a decision and choose a branch.

Explore

See how it connects

Which functions use this one and which it uses. Matches found only by name are marked as hypotheses, not facts.

Compare

Understand what changed

New, modified and removed functions between two versions, the graph before and after, and an explanation tied to the lines that justify it.

Technical views distinguish: observed in the code, declared by the author, a hypothesis, or a limit of the analysis. VibeConvity keeps those limits in plain words.

Privacy

Stays on your computer

  • Your code and its analysis
  • Indexes in your user folder, removable with one command
  • Your preferences

Never, in the alpha

  • Telemetry or analytics
  • Accounts or sign-in
  • External AI — blocked even if keys exist
  • Running your project

Only when you choose

  • Copying a question for your own agent
  • Sharing a diagnostics text you reviewed
  • Reports you write yourself

Honest limits: browser extensions or security software that inspect local pages can read what Convity shows (it warns you when it detects injected resources). The alpha has not had an independent security audit. This website adds no cookies, analytics or third-party resources. Its host, GitHub Pages, logs visitor IP addresses for security. Questions

How do I install it?

Extract the ZIP into a new folder and open Convity.cmd. Node.js and TypeScript are included; nothing is installed system-wide and you do not need administrator rights. The package is not code-signed yet.

What do I need?

Windows 11 x64. Git only to compare commits of your own repository; Python only for .py files. No account, no API key.

Which languages does it understand?

JavaScript, TypeScript and Python.

Does my code leave my computer?

Not through Convity. External AI is blocked in the alpha and there is no telemetry. Questions for your agent are copied, never sent.

Does it work with Claude Code and Codex?

Optional skills open Convity from Claude Code (/convity) and Codex ($convity). They have been used for real on Windows 11 by the developer; other setups are not verified yet.

How accurate is it?

Convity describes what the code says and labels each statement as observed, declared, hypothesis or limit. Static analysis cannot know runtime values, and explanations can be incomplete. The code is always shown next to them.

Is it available? How much does it cost?

A free private alpha for 3 to 5 invited testers is being prepared. You can register your interest now; invitations depend on completion of distribution checks and evaluation terms. There is no public download or paid plan yet.

Is it open source?

No. Convity is proprietary. The public repository contains presentation material only.
