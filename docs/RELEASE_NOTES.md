# Release notes

## 0.3.0-alpha.3 — private alpha (prepared, not yet distributed)

- **Three-step quick intro** on first launch: VibeConvity, a real branch choice in the flow graph, and the demo's before/after change with its explanation. The full 20-step tour and "explore on my own" remain available.
- Tour bubbles never cover the highlighted area and keep their buttons visible on small windows.
- **VibeConvity** mode for people new to code, and **Convi**, the tour's mascot.
- **Changes** mode explains argument differences in calls and links each difference to its lines.
- Reproducible Windows package with integrity manifest, component list (SBOM) and a safe uninstaller.

## 0.3.0-alpha.1 — private alpha (internal)

- First Windows 11 x64 portable package with Node.js and TypeScript included, a synthetic demo, privacy-safe diagnostics and agent skills set up with confirmation.

Earlier versions were internal development milestones.
