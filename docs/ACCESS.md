# Requesting alpha access

The alpha is small on purpose: **3 to 5 testers at a time**, so every report gets attention. We are looking for:

1. People who use **Claude Code or Codex** to write code.
2. People building apps with AI who are **new to programming** ("vibe coding").
3. Developers who need to **understand changes made by an agent**.
4. **Students** and people learning to program.

You need a computer with **Windows 11 x64** and a GitHub account (the support channel is a private GitHub repository).

## How to ask

**Register your interest through the [Alpha access request form](https://github.com/convderover/convity-app/issues/new?template=alpha-access.yml).** Requests are public. The form asks only:

- which of the four groups above fits you best;
- whether you use Claude Code, Codex, both or neither;
- what you would like to understand better about your code (one or two sentences).

**The request is a public issue on GitHub.** Do not include your email, real name, company, code or any private information. We reply in the issue and, if you are selected, ask you there how you prefer to receive the invitation.

## What happens next

- We read every request. Selection depends on the mix of profiles we need, not on the order of arrival.
- Invitations will begin only after distribution checks and evaluation terms are completed. Registering interest does not grant access. There is no public download. Selected testers will receive private instructions and a support invitation.
- We never ask for your repositories, agent conversations or credentials.
- You can withdraw at any time; tell us in the issue or the support channel and we will close it.
