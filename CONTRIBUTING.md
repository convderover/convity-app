# Contributing

Convity is a proprietary product built by one person. **The source code is not public and we do not accept code contributions** through this repository.

You can still help a lot:

- **Try the alpha** and tell us where you got confused. [Request access](docs/ACCESS.md).
- **Report problems** in the documentation or the website here, as issues.
- **Suggest improvements** to the explanations: what would you have needed to understand a change?

## Before you post

- Use made-up code to show a problem. Never paste private code, file paths from your computer, keys, cookies or activation links.
- Do not post personal data about yourself or others.
- Keep it respectful. Issues that are abusive, promotional or off-topic will be closed.

Security issues: follow [SECURITY.md](SECURITY.md) instead.
